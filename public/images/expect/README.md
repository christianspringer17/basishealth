# What to expect carousel

Editorial photography for the homepage slideshow (`ExpectSection`). Regenerate from source PNGs with:

```bash
node scripts/install-expect-images.mjs
```

Source assets live in the Cursor workspace `assets/` folder (attached uploads). Outputs are landscape `1600×1000` and portrait `900×1125` WebP.

| File | Step |
|------|------|
| `step-1-eligibility.webp` | Eligibility screening (desktop) |
| `step-1-eligibility-mobile.webp` | Eligibility screening (mobile) |
| `step-2-protocol.webp` | Personalized protocol (desktop) |
| `step-2-protocol-mobile.webp` | Personalized protocol (mobile) |
| `step-3-care.webp` | Ongoing adaptive care |
| `step-4-literacy.webp` | Metabolic literacy (desktop) |
| `step-4-literacy-mobile.webp` | Metabolic literacy (mobile) |
